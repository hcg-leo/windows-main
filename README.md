### windows configuration

my personal setup for windows on my galaxy book 3 360 - thats it

```
.
├── ahk
│   └── wm.ahk
├── altsnap
│   └── AltSnap.ini
├── autounattend.xml
├── batch
│   ├── apps.bat
│   ├── config.bat
│   ├── helium.bat
│   ├── lightcraft.bat
│   ├── settings.bat
│   └── system.bat
├── books
├── cat.png
├── .gitignore
├── helium
│   ├── bookmarks.html
│   └── flags.json
├── manga
│   └── manga.bat
├── mountain.jpg
├── music
│   └── music.bat
├── oregairu.png
├── README.md
├── terminal
│   └── settings.json
├── vagabond.png
└── zed
    ├── settings.json
    └── themes
        └── nord.json
```

1. install windows with `autounattend.xml`
2. run `apps.bat`, `config.bat`, `settings.bat` and `helium.bat` from `batch`
3. run `system.bat` as admin, then restart

> tree: `git ls-files | tree --fromfile .` in wsl
