# Global instructions

## Git

- Keep commit messages short: a few words (aim for 6 or fewer) naming the main change.
  Don't list every change in the commit, e.g. `moved media bats into config`, not
  `moved manga and music bats into config batch and untracked media and claude md`.
- Commit messages are lowercase and casual.
- No punctuation in commit messages: no `+`, commas, slashes, periods (even in file
  names) or quotes. Use `and` instead of `+`.
- Never add a `Co-Authored-By: Claude ...` trailer or any other Claude/Anthropic
  attribution to commit messages.
- Never add "Generated with Claude Code" or similar attribution to commit messages or
  pull request descriptions.
